# Elric AI — iOS (native)

Native SwiftUI app that runs **Elric Lite** fully on-device with Google's
[LiteRT-LM Swift API](https://developers.google.com/edge/litert-lm/swift)
(SPM package `https://github.com/google-ai-edge/LiteRT-LM`, product `LiteRTLM`, pinned to `0.19.0`).

- Bundle id `in.elricai.app`, display name **Elric AI**, iOS 17+, SwiftUI.
- The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`
  (the `.xcodeproj` is not committed).
- Built on GitHub Actions (`.github/workflows/ios.yml`, `macos-latest`): simulator compile check +
  unsigned device build → artifact **`elric-ios-unsigned-ipa`**.

## Model
Not bundled. The app downloads it once (with resume) to Application Support, excluded from iCloud backup:

`https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm/resolve/main/gemma-4-E2B-it.litertlm`
— 2,588,147,712 bytes (Apache-2.0, ungated). The size is checked when the download finishes.

## Memory entitlement
`ElricAI/ElricAI.entitlements` requests `com.apple.developer.kernel.increased-memory-limit`.
It only takes effect when the app is signed with a provisioning profile that includes the
**Increased Memory Limit** capability (enable it for the App ID in the Apple Developer portal).
Unsigned / re-signed builds without it run with the default memory limit, so Elric Lite may fail to
load on phones with less RAM. If loading fails, the app shows the exact error text plus device memory.

## Build locally (on a Mac)
```bash
brew install xcodegen
cd ios && xcodegen generate && open ElricAI.xcodeproj
```

## Installing on an iPhone
The CI `.ipa` is **unsigned**; iOS will not install it as-is.
- **TestFlight / App Store** (recommended): paid Apple Developer Program ($99/yr). Fill the secrets
  listed in the disabled `signed` job of `ios.yml` and enable it.
- **Free Apple ID sideload**: re-sign the unsigned `.ipa` with a tool such as Sideloadly or AltStore on
  a Windows PC/Mac. Free-account signatures expire after 7 days, and the increased-memory-limit
  entitlement is generally not available to free accounts.
