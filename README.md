# Elric AI

**AI you can rely on.** An offline-first study and shopping assistant for India, in English and Hindi.

- Study help runs fully on your phone (on-device Gemma models), private by default.
- Shopping mode uses the internet for live, time-stamped prices.

Status: early development (v0.1.0). Android first, then web and iOS.
